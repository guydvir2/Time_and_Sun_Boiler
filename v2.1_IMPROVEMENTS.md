## 🚀 **HOW IT WORKS:**

### **First Run:**
```bash
python main.py
```

**What happens:**
1. Creates `data/` directory structure
2. Migrates old files automatically:
   - `config.ini` → `data/config/config.ini`
   - `runtime_settings.json` → `data/config/runtime_settings.json`
   - `boiler.log` → `data/logs/boiler.log`
   - `daily_log.csv` → `data/csv/daily_log.csv`
3. Starts normally

### **Subsequent Runs:**
- Everything loads from `data/` automatically
- No migration needed
- Clean root directory

## 🎨 **ALTERNATING ROW COLORS:**

```python
# Dark theme colors for LUT table
self.lut_tree.tag_configure("oddrow",  
    background="#2a2a2e",  # Slightly lighter
    foreground="#e0e0e0"   # Light text
)

self.lut_tree.tag_configure("evenrow",
    background="#1e1e1e",  # Darker (matches app BG)
    foreground="#e0e0e0"   # Light text
)
```

**Result:** Rows alternate between dark gray and darker gray, making it easy to track across columns.
